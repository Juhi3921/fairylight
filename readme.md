# Fairylight

A whimsical, zero-gravity physics playground where stickers, notes, and butterflies float, bounce, and can be flung across a twilight meadow.

Built with plain **HTML**, **CSS**, and **vanilla JavaScript**


## Features

- **Real physics** — powered by [matter-js](https://brm.io/matter-js/).
- **Drag & fling** — grab any floating item and throw it; it bounces off walls and other items.
- **Butterfly burst** — click a butterfly to pop it into sparkles; it respawns somewhere new a moment later.
- **Shake the world** — toggle a gentle snow-globe shake, then toggle it off to return to a calm drift.
- **Sound effects** — optional synthesized audio for bursts, respawns, and shake/calm. Toggle on/off; your choice is remembered in `localStorage`.
